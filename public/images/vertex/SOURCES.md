## Approved reference differences

These are official brand files, not extracted originals from the supplied screenshot. The Next.js icon is circular, while the reference uses a rounded square. The Docker mark is the official solid silhouette, while the reference has a different illustration. The user explicitly approved these substitutions before implementation.

The tutorial's `public/Assets.zip` does not contain separate avatar or course-logo files. Its [home-page prompt](https://github.com/jsmastery-pro/vertex-learning-platform/blob/main/prompts/home-page.md) specifies an initials avatar and an approximate Docker mark, so it does not establish a source for the photograph in the reference.
